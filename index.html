01 · Problem, Scope & Objectives

Pixels are not perception

Urban driving is an open-world visual problem. A box on an image is not enough: a car in the oncoming lane is not the same hazard as a car two metres ahead in the ego path.

SEVEN QUESTIONS EVERY FRAME MUST ANSWER
  • 1What objects are present — class + confidence.
  • 2Where they are — box in the image plane.
  • 3Which of them lie in the driving corridor.
  • 4How they move — identity across frames.
  • 5How close — monocular D = (H · F) / h.
  • 6Approaching? — closing speed and TTC.
  • 7Dangerous? — rule table → CONTINUE / WARNING / BRAKE.

Honesty constraint: if ego speed is not sensed it is published as null. Poor lane evidence is labelled uncertain — never faked.

EIGHT DELIVERED OBJECTIVES
1. Real-time detection of road objects (YOLO11n).
2. Identity tracking across frames (ByteTrack).
3. Corridor perception — in / near / outside / uncertain.
4. Relative motion from consecutive frames.
5. Monocular distance from box height.
6. TTC + four-level risk (SAFE…CRITICAL).
7. Recorded video and live camera input.
8. Nine-page dashboard of every measured number.

1 · Input

VideoCapture or camera index. Routes /api/source/video|camera. Play / pause / resume / restart / stop. Idle frame: NO INPUT SOURCE.

2 · Detect

YOLO11n track/predict · conf 0.35 · IoU 0.45 · imgsz 640. 182 layers · 2 591 790 params. Swap COCO 80-class or BDD 10-class .pt live.

3 · Track

persist=True · bytetrack.yaml default · botsort.yaml optional. Registry keyed by ID. Disable tracking → TTC unavailable (correct).

4 · Dynamic ROI

Gray → 5×5 blur → Canny → HoughLinesP → RANSAC / quadratic. Reuse ≤ 8 with decay, then fallback trapezoid. Never drops a box.

5 · Distance

D = (H · F) / h · F default 700 px (live-editable). Smooth window 5. Heights: person 1.70 · car 1.50 · truck/bus 3.20 · train 3.50 m.

6 · TTC + Risk + Serve

Closing speed from 8-sample deque. TTC cap 60 s. CRITICAL D≤3 m / 1 s → BRAKE. FastAPI MJPEG + WS ~5 Hz · nine pages.

ROIObjectAssociator returns in / near / outside / uncertain. Safety uses boolean in_path only. Overlay HUD draws corridor, boxes, IDs, distance. JPEG quality 80. Config patches deep-merge under a lock.

LIMITS

Inherent

Pinhole D is not LiDAR. Classical ROI fails at night, rain, worn paint, intersections. Risk ignores class and ego speed (null). Train class unlearnable. No auth — localhost only.

NEXT

Harden

JSONL logs, incident stills, optional ego-speed, F calibration wizard, per-class risk, TestClient smokes, ONNX / TensorRT, Dockerfile, config persistence.

NEVER

Non-goals

No actuation. No fake speed. No ADAS / ISO 26262 claim. No stereo/LiDAR in this Mini Project. WARNING/BRAKE are UI labels.

09 · Conclusion

From detection to understanding

The Mini Project built a camera-based real-time perception system for research, not a self-driving stack. Existing methods, composed, measured, and discussed without exaggeration.
